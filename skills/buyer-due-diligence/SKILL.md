# 买家背调与采购能力核验

## Purpose

把一条买家线索（公司名 / 官网 / 联系人 / 邮箱 / 领英）查成一份可决策的尽调报告：
这家公司是否真实存在、做什么生意、有多大采购能力、有没有风险信号、下一步怎么跟。

**每一条结论都必须标注信息来源和获取时间。** 查不到就写「未核实」，不写推测。

## When to Use

- 收到询盘后要做客户资质核验
- 展会/名片/领英来的线索，判断值不值得投入跟进
- 大额订单或首单前做风险排查
- 老客户年度复审

## Inputs

至少给一项，越多越准：

| 字段 | 说明 | 是否必填 |
|---|---|---|
| company_name | 公司全称（含 Inc / LLC / GmbH 等后缀） | 二选一 |
| website | 官网域名 | 二选一 |
| contact_name | 联系人姓名与职位 | 否 |
| email | 邮箱（重点看是否企业域名） | 否 |
| linkedin | 领英公司页或个人页 | 否 |
| country | 国家/地区 | 否 |
| notes | 询盘内容、历史沟通记录 | 否 |

## Workflow

按顺序执行，**每一步都要记录来源 URL 和抓取时间**。

### 1. 域名与邮箱核验（最快出结论的一步）

- 邮箱域名是否等于官网域名？不一致要标黄（用 gmail/yahoo/outlook 直接标红）
- 官网能否访问、是否有 SSL、是否有实体地址与联系电话
- whois 注册时间：不足 1 年的标黄，不足 6 个月的标红

### 2. 官网画像

用浏览器打开官网，抓这五项，**抓不到就写未获取**：

- 主营品类（是否与我方产品线重合）
- 成立年份 / 公司简介中的规模描述
- 是否有 B2B 询价入口、经销商招募页（有 → 更可能是贸易商/分销）
- 产品线深度（SKU 数量级、是否有多品牌代理）
- 地址与联系方式（是否为真实办公地址，还是仅一个邮箱表单）

### 3. 领英与社媒交叉验证

- 领英公司页：员工人数区间、成立年份、所在地是否与官网一致
- 关键人：联系人职位是否匹配其采购权限（Purchasing Manager / Owner / Buyer 优先）
- 社媒活跃度：近 6 个月是否有更新（长期停更标黄）

### 4. 贸易行为线索

- 官网/领英是否提及「import」「sourcing from China」「distribution」
- 是否出现在行业展会参展商名单
- 是否有多语言站点（说明有跨境采购经验）

### 5. 风险标记

命中任一条必须显式写进报告：

| 风险信号 | 等级 |
|---|---|
| 免费邮箱 + 无官网 + 无公司地址 | 高 |
| 域名注册 < 6 个月 | 高 |
| 要求代收货款 / 先行支付「清关费」「代理费」 | 高（可能是诈骗） |
| 索要我方客户名单或同行报价单 | 高 |
| 官网主营与我方产品完全不重合 | 中 |
| 领英员工数 < 5 且成立 < 2 年 | 中 |
| 官网长期无更新、无产品页 | 中 |
| 邮箱与域名不一致 | 低 |

## Scoring

采购能力分四档，**按「能查到的证据」判，不按感觉判**：

| 档位 | 判定标准（满足越多越靠上） |
|---|---|
| **S** | 官网完整 + 领英 50 人以上 + 明确进口/分销业务 + 有中国采购痕迹 |
| **A** | 官网完整 + 领英可查 + 主营与我方重合 + 有 B2B 采购入口 |
| **B** | 官网存在但信息简略，或仅领英可查，主营部分重合 |
| **C** | 只有询盘文字，公司信息几乎查不到 |
| **风险** | 命中任一高风险信号，不论其他项 |

## Output Format

```
## 买家背调报告

**公司：ABC Trading Co.**
**结论：A 类 · 可进入常规跟进**
**核验时间：2026-11-19 21:30**

### 一、企业画像
| 项 | 结论 | 来源 |
|---|---|---|
| 官网 | abctrading-usa.com，可访问，有 SSL | 直接访问 |
| 成立年份 | 2012 | 官网 About 页 |
| 规模 | 领英显示 11-50 人 | 领英公司页 |
| 主营 | 汽车与工业工具分销 | 官网产品页 |
| 与我方重合度 | 高（LED 工作灯属其工具类目） | 人工判断 |
| 采购角色 | 分销商（有经销商招募页） | 官网 Distributor 页 |

### 二、采购能力判断：A
依据：
- 官网有完整产品线与 B2B 询价入口
- 领英可查、员工 11-50 人、近 3 个月有更新
- 明确服务 120 家零售门店（询盘自述，未独立核实）
- 邮箱为企业域名，与官网一致

### 三、风险标记
- 无高风险信号
- 低风险：询盘自述的「120 家门店」未在官网找到佐证，建议首单控制金额

### 四、未知项（需客户或第三方补充）
- 年采购规模
- 是否已有中国供应商
- 付款方式偏好

### 五、下一步动作
1. 按 A 类客户 24 小时内回复，报阶梯价
2. 回复中确认：目标市场、认证要求、付款条件
3. 首单建议 ≤ 5000 USD，走信保
4. 补充核验：查其是否为行业协会成员
```

## Boundaries

- **不推测公司规模**：查不到员工数就写「未获取」，不写「看起来是一家中小型公司」
- **不把询盘自述当事实**：客户说自己大，标「自述，未核实」
- **不输出未经核实的好评**：没查到就写没查到，不要用「应该」「大概」填空
- **不做信用评级**：本 Skill 只做公开信息核验，不涉及征信、不判断支付能力
- **合规边界**：只使用公开渠道（官网、领英、公开展会名录），不获取非公开数据、不爬取需登录的数据库
- **每条结论必须有来源**：来源写不出的一律降为「待核实」
