# 直通车（P4P）诊断报告

## Purpose

把推广账户的钱花在哪、换回了什么算清楚，找出**正在漏钱的关键词**，并给出可以今天就执行的调价与否定词清单。

一句话目标：**同样的预算，多拿询盘；或者同样的询盘，少花钱。**

## When to Use

- 月度推广复盘
- 花费涨了但询盘没涨
- 询盘成本高于可接受范围，要压缩
- 新接手账户，做基线体检

## Inputs

**账户层**：总花费、总曝光、总点击、总询盘、统计周期
**关键词层**（核心）：关键词、匹配方式、出价、曝光、点击、点击率、花费、平均点击花费、询盘数

有则更好：推广计划分组、投放地域、投放时段、落地页 URL、近 7 天趋势。

## 核心指标与算法

| 指标 | 公式 | 用来判断 |
|---|---|---|
| 点击率 CTR | 点击 / 曝光 | 素材与关键词相关性 |
| 平均点击花费 PPC | 花费 / 点击 | 出价是否虚高 |
| 点击转化率 CVR | 询盘 / 点击 | 落地页与商品承接能力 |
| 询盘成本 CPI | 花费 / 询盘 | **最终考核指标** |

三者关系必须一起看：`CPI = PPC / CVR`
所以降询盘成本只有两条路——**降 PPC** 或 **提 CVR**。诊断时必须说清是哪一条出了问题。

## 关键词四象限（核心方法）

按「花费占比」×「是否出询盘」分四类：

| 象限 | 特征 | 判定 | 动作 |
|---|---|---|---|
| **主力词** | 花费高 + 有询盘 | 现金牛 | 保出价、拓同义词与长尾、观察排名 |
| **漏钱词** | 花费高 + 零询盘 | 正在烧钱 | **优先处理**：降价 30%、改精确匹配、加否定词；两周仍无询盘则暂停 |
| **机会词** | 花费低 + 有询盘 | 被压着 | 提出价 20-30%、放宽匹配、扩同类词 |
| **观察词** | 花费低 + 零询盘 | 还没跑出量 | 不动，累积至少 50 次点击再判 |

**判定阈值**（避免样本太小误杀）：
- 花费占比 ≥ 5% 才算「高花费」
- 点击 ≥ 50 次仍零询盘，才判「漏钱」，否则进「观察」
- 这说明为什么不能看到零询盘就砍词——样本不够时砍掉的可能是未来的主力

## 诊断顺序（必须按这个顺序，否则会误判）

1. **先看账户 CPI**：是否高于可接受线，高出多少
2. **拆因**：CPI 高是因为 PPC 高，还是 CVR 低？
   - PPC 高 → 出价问题、行业竞价激烈
   - CVR 低 → 落地页问题、商品与词不匹配、价格/MOQ 劝退
3. **算漏钱规模**：漏钱词花费占总花费的比例（这个数字最有说服力）
4. **查匹配方式**：广泛匹配是否跑出大量无关搜索词
5. **查地域与时段**：是否有低效地域在持续消耗
6. **给清单**：止血清单（省钱）、加投清单（增量）、落地页整改清单

## Output Format

```
## 直通车诊断报告

**周期：2026-10-20 ~ 2026-11-19**
**结论：漏钱词占花费 34%，先止血再谈增长**

### 一、账户体检
| 指标 | 本期 | 上期 | 判断 |
|---|---|---|---|
| 花费 | $3,860 | $3,420 | +12.9% |
| 点击 | 1,820 | 1,690 | +7.7% |
| 询盘 | 26 | 31 | **-16.1%** |
| CPI | $148 | $110 | **+34.5%，恶化** |
| PPC | $2.12 | $2.02 | 略升 |
| CVR | 1.43% | 1.83% | **下降，问题在这** |

**归因：不是出价贵了，是点击转化率掉了 0.4 个点。**
钱花得更多、点击也更多，但询盘变少 → 问题在落地页承接，不在关键词。

### 二、漏钱词（优先处理，可省 $1,310/月）
| 关键词 | 花费 | 点击 | 询盘 | 动作 |
|---|---|---|---|---|
| led work light wholesale | $420 | 198 | 0 | 降价 30% + 改精确 |
| outdoor flood light | $310 | 145 | 0 | 加否定词「solar」 |
| work lamp factory | $290 | 132 | 0 | 暂停（点击 132 次零询盘） |
| portable lighting | $290 | 128 | 0 | 改短语匹配 |

### 三、机会词（加投，预计 +9 询盘/月）
| 关键词 | 花费 | 询盘 | CVR | 动作 |
|---|---|---|---|---|
| rechargeable work light | $95 | 6 | 6.3% | 提价 25%，放宽匹配 |
| ip65 led work light | $62 | 4 | 6.5% | 提价 20%，加长尾 |

### 四、落地页问题（CVR 下降的真因）
- 主推落地的详情页缺 MOQ 与认证信息，B 端买家看不到直接离开
- 首屏无视频，平均停留 28 秒
- 建议：详情页首屏补 MOQ/交期/认证三件套，加 60 秒工厂视频

### 五、只做一件事
**把 1,310 美元从漏钱词挪到机会词，同时改主推详情页首屏。**
预算不变，按机会词当前 CVR 推算，月询盘可从 26 条回到 33 条左右。

### 六、执行清单
| 优先级 | 动作 | 影响 |
|---|---|---|
| P0 | 4 个漏钱词降价/暂停 | 省 $1,310/月 |
| P0 | 加 6 个否定词 | 减少无效点击 |
| P1 | 2 个机会词提价 | +9 询盘/月 |
| P2 | 详情页首屏改造 | 全账户 CVR 回升 |
```

## Input Handling

- **只有账户汇总没有关键词明细**：只能做账户级诊断，明确说明「无法定位漏钱词」，并要求导出关键词报表
- **周期不足 14 天**：拒绝下结论，样本不够会误判，建议累积到 14-30 天
- **没有询盘数据只有点击**：改用 CTR 与 PPC 判断，明确标注「无法评估转化」

## Boundaries

- **不保证效果**：给的是基于历史数据的概率建议，不承诺「一定降本 30%」
- **不碰违规操作**：不建议刷点击、恶意点击对手、虚假询盘
- **不替客户改价**：价格与 MOQ 只做提示，是否调整由业务决定
- **样本不足不下判断**：点击 < 50 的词一律进观察区，不砍
- **区分品类差异**：不同二级类目的 PPC 基准差很大，不做跨类目对比
