# 品牌广告诊断报告

## Purpose

品牌广告买的是**位置和曝光**，不是点击。所以不能用直通车那套「询盘成本」直接判生死。

本 Skill 要做的是：把品牌广告的漏斗拆开，分清「曝光不够」「素材不吸引」「落地接不住」三种问题，
并给出一个诚实的归因口径——**哪些效果是它直接带来的，哪些是它间接撑起来的**。

## When to Use

- 顶展/问鼎/明星店铺投放周期结束，要做复盘
- 续费决策前，判断这个位置值不值
- 曝光很大但询盘没涨，怀疑素材或落地页
- 品牌广告与直通车预算如何分配

## Inputs

**位置信息**：广告位类型（顶展/问鼎/明星店铺）、投放关键词或位置、投放周期、合同金额
**数据层**：曝光量、点击量、点击率、带来的访客数、询盘数
**对照数据**（很重要）：同期自然流量变化、品牌词搜索量变化、直通车数据

## 漏斗模型（诊断的唯一骨架）

```
曝光 ──点击率──> 点击 ──到达率──> 访客 ──承接率──> 询盘
```

四个环节，每个环节对应一类问题：

| 环节 | 指标 | 低于基准说明什么 |
|---|---|---|
| 曝光 → 点击 | CTR | 素材/主图/文案不吸引，或位置与受众不匹配 |
| 点击 → 访客 | 到达率 | 落地页加载慢、跳转异常、地域屏蔽 |
| 访客 → 询盘 | 承接率 | 详情页接不住，价格/MOQ/认证缺失 |
| 曝光量本身 | 曝光完成率 | 位置没跑满，或关键词覆盖不足 |

## 归因规则（这份 Skill 最重要的一段）

品牌广告的效果**不能只看直接询盘**，但也不能全算成它的功劳。按三层拆：

1. **直接归因**：通过广告位点击进来的访客产生的询盘 — 可明确计算
2. **间接归因**：广告曝光后，买家记住品牌名，之后主动搜索品牌词进来的流量 — 对比投放前后品牌词搜索量变化
3. **不计入**：同期自然增长、季节性上涨、直通车带来的量 — 这些不能算品牌广告的功

**输出时必须把三层分开写，并明确说明「第三层无法归因」。** 这是诚实，也是专业。

## Workflow

1. **先算曝光完成率**：实际曝光 / 合同承诺曝光。低于 80% 先找平台，不是素材问题
2. **算三率**：CTR、到达率、承接率，逐项与该位置历史或同类位置对比
3. **定位断点**：漏斗哪个环节掉得最狠，问题就在那一环
4. **素材诊断**：主图是否 3 秒内说清「你是谁、卖什么、凭什么选你」
5. **间接效应核查**：对比投放前后品牌词搜索量与自然访客
6. **续费建议**：给出「继续 / 换位置 / 停」三选一，并说明依据

## Output Format

```
## 品牌广告诊断报告

**位置：关键词问鼎（led work light 等 5 词）**
**周期：2026-10-01 ~ 2026-11-19 · 合同金额 $4,200**
**结论：曝光达标，问题在点击率，素材要改，位置值得续**

### 一、漏斗拆解
| 环节 | 本期 | 基准 | 判断 |
|---|---|---|---|
| 曝光 | 182,000 | 180,000（合同） | 完成率 101%，正常 |
| 点击 | 1,456 | — | — |
| CTR | 0.80% | 1.20%（同类位置） | **偏低 33%，主要问题** |
| 访客 | 1,398 | — | 到达率 96%，正常 |
| 询盘 | 18 | — | 承接率 1.29% |
| 直接询盘成本 | $233 | — | 单看这个数会误判 |

### 二、断点定位
**断点在曝光→点击环节，CTR 只有 0.80%，比同类位置低三分之一。**
访客到达和详情页承接都正常，说明不是落地页问题，是**素材没让人想点**。

### 三、素材诊断
当前主图问题：
- 首图是白底产品图，缩到广告位尺寸后看不清是什么
- 无卖点文字，买家无法在 1 秒内判断是否相关
- 无差异化信息（认证、交期、MOQ）
建议：换成「场景图 + 3 个卖点短句」的版式，测试 2 版对比 CTR

### 四、归因（三层分开看）
| 层次 | 数值 | 说明 |
|---|---|---|
| 直接归因 | 18 条询盘 | 从广告位点击进入并产生询盘 |
| 间接归因 | 品牌词搜索 +42%（同期） | 曝光带来的记忆效应，可能存在部分重叠 |
| 无法归因 | — | 同期自然增长与季节性因素未剔除，不做估算 |

**说明：间接归因含重叠，不能与直接归因相加。**

### 五、续费建议：继续，但要换素材
- 曝光量稳定达标，位置本身没问题
- CTR 有明确提升空间（同类位置 1.2%，当前 0.8%）
- 按 1.2% 测算，同样曝光可多出约 730 次点击，按当前承接率约多 9 条询盘
- 建议续一个季度，但要求素材在 2 周内迭代一版

### 六、动作清单
| 优先级 | 动作 | 预期 |
|---|---|---|
| P0 | 主图换成场景图 + 卖点短句 | CTR → 1.0% 以上 |
| P1 | 加 2 个高相关关键词到问鼎 | 提升曝光精准度 |
| P2 | 落地页首屏补 MOQ/认证/交期 | 承接率提升 |
```

## Input Handling

- **只有曝光和点击**：只能算 CTR，明确说明「无法评估询盘转化」，不要推测
- **没有同期对照数据**：间接归因部分直接写「无对照数据，不做估算」
- **周期不足一个月**：CTR 可以看，询盘样本太少，结论标注「样本不足」

## Boundaries

- **不做虚假归因**：不能把自然增长说成广告效果，也不能因为「品牌广告本来就看长期」就不给数据
- **不承诺曝光或排名**：平台位置受竞价与库存影响，不保证具体量级
- **不评价平台**：发现曝光未达标时，建议核对合同并联系平台，不做主观指责
- **间接效应必须标注重叠**：品牌词搜索提升含自然因素，不能全额归功
- **不做品牌策略建议**：本 Skill 只做投放数据诊断，不涉及品牌定位与视觉设计
